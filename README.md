3. TIPOGRAFIA

==================================================

A tipografia é uma das características mais importantes da capa.

Criar uma combinação de duas famílias tipográficas:

TIPOGRAFIA 1 — TÍTULOS CLÁSSICOS:

Utilizar uma fonte serifada elegante semelhante à aparência de:

Cormorant Garamond

ou

Playfair Display

Preferência:

Cormorant Garamond.

Utilizar para:

- títulos

- números

- subtítulos importantes

- frases de impacto

TIPOGRAFIA 2 — CALIGRAFIA:

Utilizar uma fonte manuscrita elegante semelhante à utilizada na palavra "Rezando" e no nome "Marcos Nascimento".

Sugestões:

Brittany Signature

Great Vibes

Allura

Parisienne

Preferência:

Great Vibes ou Allura.

Utilizar a fonte manuscrita SOMENTE para palavras e frases especiais.

NÃO utilizar fonte manuscrita em grandes blocos de texto.

TIPOGRAFIA 3 — TEXTO:

Para textos corridos utilizar uma serifada ou sans-serif extremamente legível.

Preferência:

Lora ou Montserrat.

A combinação visual deve lembrar:

LIVRO CLÁSSICO + CARTA PESSOAL + DEVOCIONAL.
